# 🏦 ApexBank – Responsive Banking Portal

A modern, responsive, and professional **online banking portal** built using **HTML, CSS, and JavaScript**. ApexBank provides a clean 3D-inspired banking interface with easy navigation for common banking services.

## ✨ Features

* 🔐 Secure Login Interface
* 📊 Interactive Banking Dashboard
* 💸 Money Transfer
* 💳 Payment Management
* 🏦 Loan Management
* 👤 User Profile
* 📱 Fully Responsive Design
* 🎨 Modern 3D UI Effects
* 🌙 Professional Banking Theme
* ⚡ Smooth Animations and Transitions
* 📈 Account & Transaction Overview

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, responsive design, animations and 3D effects
* **JavaScript** – Interactive functionality
* **Bootstrap** – Responsive components
* **Font Awesome** – Icons

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/mahalak20607-ux/Banking-portal.git
```

2. Open the project folder:

```bash
cd Banking-portal
```

3. Open `index.html` in your browser.

You can also use **Live Server** in VS Code for development.

## 💻 Main Modules

### 🏠 Dashboard

Displays account information, balance, recent transactions, and banking shortcuts.

### 💸 Transfer

Allows users to access the money-transfer interface.

### 💳 Payments

Provides a dedicated interface for managing digital payments.

### 🏦 Loans

Provides loan information and a professional loan application interface.

### 👤 Profile

Displays user information and account-related details.
